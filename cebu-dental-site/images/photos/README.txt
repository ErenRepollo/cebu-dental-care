The "Take a look around" gallery has a built-in lightbox: click any photo to view it
large, use the arrows or your keyboard (<- / -> / Esc) to navigate.

TO USE YOUR OWN PHOTOS: overwrite these files with the exact same names (keep the
dimensions above if you can, and compress them first at squoosh.app so the site stays
fast). No code changes are needed - the site picks the new files up automatically.
Use your own clinic photos, or free-to-use stock (Unsplash, Pexels) and check the license.
